# personal-portfolio
Taking the structure from the Basic HTML Website Project and applying various CSS techniques to enhance its appearance and responsiveness.

# Key aspects of this project
- Fully styled, responsive website with the same structure as the Basic HTML Website Project
- Consistent use of a chosen color scheme and typography
- Proper use of CSS techniques like Flexbox, media queries, and the box model
- A responsive navigation bar and well-styled contact form

Full details of the project is linked here: [Personal Portfolio](https://roadmap.sh/projects/portfolio-website)
